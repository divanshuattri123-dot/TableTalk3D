# Roadside leaf texture

Created with the built-in image-generation tool on 1 November 2026 for the
existing Unity mobile scene. Original output remains in the local generated-image
folder; RoadsideLeaves.png is the project copy. This is new foliage art, separate
from the supplied APK-derived models. Engine import uses a 1024-pixel limit,
mipmaps, alpha coverage preservation and trilinear filtering.

Final generation prompt:

Create a production game foliage albedo texture, square 1024x1024. A dense irregular patch of small realistic deciduous Indian roadside leaves, neem-like and broad oval mixed leaves, seen face-on in flat neutral diffuse lighting. Rich natural sage and medium olive greens with softly sunlit yellow-green tips; fine subtle veins, natural variation, realistic photography quality. The leaves overlap into an organic leaf canopy patch filling the square, with small scattered transparent holes between leaves and a few larger irregular transparent openings; high foliage coverage approximately 85%. Leaf size roughly 30-60 pixels in a 1024 image, with no single large focal leaf. Texture designed to repeat across rounded 3D tree canopy clumps, no visible trunk, no branches, no landscape, no perspective, no baked cast shadows, no vignette, no words, no border. Transparent background with clean natural alpha-cut edges. Keep overall contrast restrained so it reads naturally on a small phone display, no black leaf outlines, no cartoon, no saturated neon green. This is the actual game texture, not a mockup or tree illustration.
