Privacy & support

Test-build notice. Publisher contact setup is pending before public store release.

Playing as a guest

No email, password or date of birth is required to play. Use a nickname rather than your real name or contact details. Children should play with people they know.

On this device

The game saves your guest nickname, preferences, selected pieces, preview unlocks and room-seat IDs in local application storage. These records let you return to a table on the same installation. They are not a cloud account. Android device backups may include application data according to your device settings; the publisher does not operate cloud profile sync.

Shared room information

When you join, the server receives a randomly generated player ID, nickname, colour and piece choices, and gameplay actions. Other people with the room code can see the room roster, balances, deeds, trades and game history. Treat the room code as an invitation and share it with people you trust.

Hosting and connection data

Cloudflare hosts realtime rooms and game assets. GitHub Pages hosts the browser game. These providers receive connection information such as IP addresses and browser requests when serving the game, subject to their own policies. The game has no advertising or analytics SDK. Technical server errors may be logged to diagnose failures.

Ads and purchases

This build serves no live ads, collects no payment details and makes no charges. Preview editions may include explicitly labelled local test unlocks. The Play test candidate disables preview transactions and sample ads.

Retention and removal

Saved rooms currently have no automatic expiry. They remain until removed by the publisher or the hosting service. Clearing this app’s storage in Android Settings removes local profile, preferences and saved seats; it does not remove an existing shared room. Reinstalling or clearing storage can prevent you from returning to that seat.

Questions and deletion requests

A public support email is not configured yet. Do not put personal information in public GitHub issues. The publisher must configure a private contact for privacy and room-deletion requests before public store release.

Changes

This notice describes the current test build. Adding accounts, analytics, ads or real purchases requires an updated notice and the relevant store declarations before those services are enabled.

Technical support

Public bug reports. Do not post personal information in public issues.
